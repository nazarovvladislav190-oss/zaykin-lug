# Зайкин луг

Уютная 3D-игра в браузере: зайка находит потерявшихся цыплят и отводит их к маме-курочке, собирает морковки, клубнику и звёзды и покупает себе наряды. Проиграть нельзя.

**Играть:** откройте адрес GitHub Pages этого репозитория (Settings → Pages).

## На телефон или планшет как приложение
- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

После первого запуска игра работает и без интернета.

## Устройство
- `index.html` — вся игра: сцена, зверята, интерфейс, звуки, сохранение в localStorage.
- `lib/three.min.js` — Three.js r128 (MIT), `fonts/` — шрифты Nunito и Pacifico (OFL). Всё лежит в репозитории, внешние сервисы не нужны.
- `sw.js` — офлайн-кэш; `manifest.webmanifest` и `icons/` — установка на экран «Домой».

Прогресс хранится в браузере устройства (ключ `zaykin-lug-v1`).
