# Зайкин луг

Уютная 3D-игра в браузере. Зайка находит потерявшихся цыплят и отводит их к маме-курочке, собирает морковки, наряжается и обустраивает свой домик. Проиграть нельзя.

**Играть:** https://nazarovvladislav190-oss.github.io/zaykin-lug/

## На телефон или планшет как приложение
- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран».

После первого запуска игра работает и без интернета.

## Устройство
Сборки нет: это обычные файлы, которые браузер загружает как есть.

- `index.html`, `css/style.css` — разметка и оформление интерфейса.
- `js/main.js` — точка входа: состояния, переходы между местами, управление, камера, главный цикл.
- `js/core.js` — рендерер, сцена, свет, мультяшные материалы.
- `js/save.js` — сохранение в браузере (ключ `zaykin-dolina-v2`), перенос старого прогресса, файл сохранения.
- `js/data.js` — каталоги: шубки, наряды, мебель, отделка. Новые вещи добавляются здесь.
- `js/bunny.js` — зайка и модели нарядов; `js/furniture.js` — модели мебели.
- `js/places/meadow.js` — луг; `js/places/home.js` — домик и обустройство. Каждое новое место — новый файл здесь.
- `js/ui.js`, `js/decor-ui.js`, `js/thumbs.js`, `js/fx.js`, `js/audio.js` — интерфейс, картинки каталога, частицы, звук.
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на экран «Домой».
- `lib/three.min.js` — Three.js r128 (MIT), `fonts/` — Nunito и Pacifico (OFL).
